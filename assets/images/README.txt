# Photos manquantes du hero (page d'accueil)

Le slider de la page d'accueil attend 6 fichiers dans assets/images/ :
hero-1.jpg, hero-2.jpg, hero-3.jpg, hero-4.jpg, hero-5.jpg, hero-6.jpg

Je ne peux pas télécharger d'images protégées par droit d'auteur à ta place,
mais voici des banques 100% gratuites et libres de droit (pas d'attribution
requise) où tu peux chercher "African farmer", "smallholder agriculture",
"Togo farming", "maize harvest Africa", etc. :

- https://unsplash.com/s/photos/african-farmer
- https://www.pexels.com/search/african%20farmer/
- https://pixabay.com/images/search/african%20farmer/

Marche à suivre :
1. Choisis 6 photos qui te plaisent sur un de ces sites.
2. Télécharge-les (bouton "Download free").
3. Renomme-les exactement : hero-1.jpg, hero-2.jpg, ... hero-6.jpg
   (garde le format .jpg, convertis si besoin).
4. Dépose-les dans assets/images/ à la place de ce fichier.

Une fois fait, le slider de la page d'accueil s'affichera automatiquement —
aucune modification de code n'est nécessaire.
